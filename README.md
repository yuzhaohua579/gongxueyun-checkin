# 工学云自动打卡

基于 GitHub Actions 的工学云（蘑菇丁）自动打卡工具，电脑不用开机，云端自动打卡！

## ✨ 功能特点

- 🌥️ **云端运行**：基于 GitHub Actions，无需本地挂机
- 🔐 **安全可靠**：账号密码通过 GitHub Secrets 加密存储
- 📅 **自动跳过节假日**：自动识别法定节假日和周末
- 📍 **自定义位置**：支持自定义打卡地址和经纬度
- 📧 **邮件通知**：可选打卡结果邮件提醒
- 🔄 **自动重试**：验证码识别失败自动重试

## ⏰ 打卡时间

- **上班卡**：每天 08:00（周一至周六）
- **下班卡**：每天 17:30（周一至周六）
- 周日和法定节假日自动跳过
